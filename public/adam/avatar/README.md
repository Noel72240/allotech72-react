# Assets avatar Adam

## PNG

| Fichier | Usage |
|---------|--------|
| `adam-neutral.png` | Bulles messages, fallback poster |
| `adam-thinking.png` | Fallback « réfléchit » |
| `adam-smile.png` | Bienvenue / sourire |
| `adam-positive.png` | Confirmation |
| `adam-blink.png` | Clignement (mode PNG) |

## Vidéo (actif)

| Fichier | Usage |
|---------|--------|
| `adam-idle.mp4` | FAB + header (attente) |
| `adam-thinking-loop.mp4` | Header + indicateur pendant génération |

`ADAM_AVATAR_USE_VIDEO = true` dans `src/config/adamAvatar.js`.
