# Assets avatar Adam

Déposez ici les exports PNG définitifs (fond transparent) :

| Fichier | Usage |
|---------|--------|
| `adam-neutral.png` | FAB, bulles messages, état par défaut |
| `adam-thinking.png` | Indicateur « Adam réfléchit… » |
| `adam-smile.png` | Header, message de bienvenue |
| `adam-positive.png` | Confirmation / réponse réussie (optionnel) |
| `adam-blink.png` | Frame clignement (animation discrète) |

Tailles recommandées : **256×256** (chat), **512×512** (header haute densité).

Les fichiers `.svg` présents servent de **fallback** tant que les PNG ne sont pas fournis.
Ne pas recadrer la planche de référence — utiliser des exports individuels par expression.
