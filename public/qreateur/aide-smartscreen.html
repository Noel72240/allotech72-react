Comment passer l’étape Windows SmartScreen

Au premier lancement, Windows peut afficher « Windows a protégé votre PC ». Suis les étapes illustrées ci-dessous pour installer Qréateur Pro en toute sérénité.

Rassurez-vous : cet avertissement est normal pour de nombreux logiciels indépendants. Qréateur Pro est développé par ALLOTECH72 et téléchargé uniquement depuis notre site officiel. Il ne s’agit pas d’un virus.
1

Lancez l’installation

Double-cliquez sur le fichier Qreateur-Pro-Setup.exe reçu par email (ou la version portable).

Qreateur-Pro-Setup.exe ↓ Double-cliquez
2

Avertissement SmartScreen

Une fenêtre de sécurité Windows peut apparaître.

🛡 Windows a protégé votre ordinateur

Microsoft Defender SmartScreen a empêché le démarrage d’une application non reconnue.

Informations complémentaires
Ne pas exécuter
⚠ C’est normal : le Setup est nouveau et pas encore « réputé » chez Microsoft.
3

Cliquez sur « Informations complémentaires »

Dans la fenêtre, cliquez le lien souligné (en haut à gauche sous le texte).

🛡 Windows a protégé votre ordinateur

Microsoft Defender SmartScreen a empêché le démarrage d’une application non reconnue.

Informations complémentaires ←
Ne pas exécuter
ℹ Une nouvelle ligne apparaît avec le nom du fichier et un bouton supplémentaire.
4

Cliquez sur « Exécuter quand même »

Un nouveau bouton apparaît. Cliquez-le pour lancer l’installation.

🛡 Windows a protégé votre ordinateur

Application : Qreateur-Pro-Setup.exe
Éditeur : Inconnu

Exécuter quand même ← Ne pas exécuter
✓ Vous pouvez installer Qréateur Pro en sécurité (éditeur ALLOTECH72).
5

L’installation démarre

Suivez l’assistant jusqu’à la fin, puis activez votre licence (email d’achat + clé QRE-…).

✓ Installation terminée — lancez Qréateur Pro

Pourquoi Windows affiche ce message ?

SmartScreen protège contre les logiciels malveillants. Qréateur Pro est un logiciel récent édité par ALLOTECH72 (France), distribué hors Microsoft Store : Microsoft ne le « connaît » pas encore.

Soyez rassuré : l’application est sûre si elle vient d’ALLOTECH72.

Vérifier que le fichier est le bon

  • Source : allotech72.fr/qreateur ou email ALLOTECH72 après achat
  • Nom : Qreateur-Pro-1.0.0-Setup.exe (ou portable)
  • Propriétés Windows : produit Qreateur Pro, société ALLOTECH72
  • Doute : contact@allotech72.fr

FAQ

Est-ce dangereux ?

Non. Windows affiche cet avertissement pour les logiciels récents ou non signés. Si vous avez téléchargé Qréateur Pro depuis www.allotech72.fr, vous pouvez poursuivre l’installation.

Pourquoi Microsoft affiche ce message ?

Parce que Windows SmartScreen vérifie la réputation des nouveaux logiciels. Cela ne signifie pas qu’ils sont malveillants.

Comment vérifier que c’est bien le logiciel officiel ?

Téléchargez uniquement Qréateur Pro depuis : https://www.allotech72.fr/qreateur/
